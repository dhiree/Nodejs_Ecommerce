# E-Commerce API

## Overview
This project is an E-Commerce API developed using Node.js, TypeScript, and MongoDB. It includes functionalities such as user authentication, product categories, product variants, orders, and subcategories. The API is robustly validated using Joi.


## Features
- **User Authentication:** Secure user registration, login, and authentication mechanisms.
- **Product Categories:** Create, retrieve, update, and delete product categories.
- **Product Variants:** Manage different variations of products like size, color, etc.
- **Orders:** Handle the creation, updating, and management of customer orders.
- **Subcategories:** Manage subcategories under main product categories.



## Technologies Used
- **Node.js:** JavaScript runtime environment for server-side programming.
- **TypeScript:** Strongly typed programming language that builds on JavaScript.
- **Express.js:** Web framework for building the API.
- **MongoDB:** NoSQL database for storing and managing data.
- **Mongoose:** Object Data Modeling (ODM) library for MongoDB.
- **JWT (JSON Web Tokens):** For securing API endpoints with user authentication.
- **Joi:** Validation library used to ensure data integrity.
